# MiWRT 1.5.4.1

Everything Beam WRT released from 1.4.9 to 1.5.4, on top of MiWRT 1.4.8.1. Based on Beam WRT 1.5.4. The OpenWrt base, the kernel and the Wi-Fi drivers are the same as in 1.4.8.1, so packages you added stay as they are.

## From Beam WRT 1.4.9 to 1.5.4

- **Boots on the newest boards.** Recent BE7000 batches carry a different flash chip (ESMT, 64 bytes of spare area per page) on which no OpenWrt build started before. The flash driver now picks the error-correction strength per flash part, as the stock kernel does, and no longer keeps a freed context around. Boards that already run keep their settings and data.
- **The second slot can hold packages.** On System, Slots the spare slot and the data partition can be joined into one storage for settings and packages, about 57 MB instead of 20. The page saves a byte-for-byte copy of the slot first and can write it back later, for example to get the factory firmware back. While the slot holds packages there is no factory firmware to fall back to.
- **Factory reset works wherever the settings live**: on the data partition, a USB disk or the spare slot. It runs before the settings are mounted, resumes after a power loss and replaces only the settings, not the backup or the other files.
- **A dying USB stick no longer sends the router to the factory firmware.** When the previous boot did not finish, the router starts without USB on its built-in storage and stays reachable.
- **Faster boot**, about 8 seconds: the LVM scan skips the raw flash partitions. The CPU voltage no longer goes below the stock level.
- **Third-party install scripts stop refusing the version.** To scripts the firmware is now OpenWrt 25.12.6; MiWRT and its number stay in the banner, on Overview, in System, Build update and in the app.
- **Updates download in the background** with a progress counter, from a mirror on this repository's GitHub Pages first and from github.com second. The MiWRT checks stay: only this project's release files are accepted, and the checksum list must carry the signature of the key the image was built with, from either source.
- **roamd**: a BE7000 can join as a node under a controller running MiWRT or Beam WRT, and the controller brings roamd to the node itself. The node is reset to factory settings when it joins.
- **Zapret Manager 3.97-r2** with Steer modules from a new signed `steer` feed, and a new `extra` feed for LuCI pages that need no compiler. Its first package is `luci-app-beam-modem`, a Status, Modem page for USB modems. Both feeds are built in this repository with the MiWRT key. Steer is third-party software against provider-side blocking, installed only when chosen.

## MiWRT

- **The checked slot write knows about the storage slot.** If both write attempts fail and the other slot holds packages rather than the factory firmware, the boot is no longer pointed at it; the failure is logged to /etc/miwrt/last-upgrade.log and the boot variables stay as they are.
- **The version everywhere comes from the same place.** The banner, Overview and the app read "MiWRT 1.5.4.1" from the firmware description, since the release field now says OpenWrt 25.12.6 for the scripts.
- **Nothing else changed**: the Xiaomi board data, the country default, the 5 GHz group-key setting, the split-mode fix, the shipped packages and the app service are the same as in 1.4.8.1.

Install over MiWRT 1.4.x from System, Build update, from the app, or with sysupgrade; settings and packages are kept.
