# MiWRT 1.4.0.1

Beam WRT 1.4.0 rebuilt from the same tree with one change to the 5 GHz radio.

- **Xiaomi board data for the 5 GHz radio in single-radio mode.** The 1.4.0 image uses the generic Qualcomm reference-board entry from `ath12k-firmware-qcn9274` (board id 2). This build ships Xiaomi's own board file (stock `bdwlan.b0002` for board id 2 and `bdwlan.b1008` for 0x1008, as `board-xiaomi_be7000.qcn9274` from the port's board repository) as `board-2.bin`, plus a boot-time guard (`be7000-board-data`, before ath12k loads) that restores it if a package reinstall puts the generic file back. Measured on an RC06 under GB, channel 36 at 160 MHz: router transmit power 19 → 23 dBm, downlink to a 2×2 Wi-Fi 6E client 800 → 1,000 Mbit/s. Uplink unchanged.
- Package feed and the build-update page point at this fork (`iroham/be7000-openwrt`).

Everything else is 1.4.0. Install over 1.4.0 with sysupgrade; settings are kept.
