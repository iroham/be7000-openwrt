Beam WRT 1.4.0. Новая база OpenWrt, MLO, перенос настроек из стока, слоты и аппаратная разгрузка.

Прошивка переехала на свежий OpenWrt. Ядро теперь 6.18.52 вместо 6.18.36, драйверы Wi-Fi взяты из backports 7.2. Всё, что было в 1.3.1, работает и здесь.

Что нового

- Три режима 5 ГГц. Кроме одного радио и двух радио появился MLO. Это одна сеть Wi-Fi 7 сразу на обоих радио, нижнее работает до 160 МГц. Устройства с Wi-Fi 7 держат связь на двух каналах, старые подключаются как к обычной сети. Режим меняется без перезагрузки роутера.
- Перенос настроек из стока. При первой установке прошивка сама берёт из заводской прошивки Wi-Fi, подключение к интернету и адрес роутера. Всё это можно отменить одной кнопкой. Сама заводская прошивка при этом ничего не теряет.
- Страница Система, Слоты. На ней видно, что лежит в каждом слоте и какой загружается. Там же можно переключиться на другой слот или вернуться на заводскую прошивку, а рядом подробно описано, как это работает.
- Аппаратная разгрузка NAT на сетевом процессоре PPE. Функция экспериментальная и по умолчанию выключена. Включается на странице Сеть, Аппаратная разгрузка, там же её подробное описание.
- Если код страны выключает Wi-Fi 7 на 5 ГГц, появляется предупреждение. Кнопка рядом ставит для 5 ГГц код US.
- В документации появились рецепты для частых задач и страница замеров с методикой.

Что исправлено

- Смена режима 5 ГГц больше не может перезагрузить роутер.
- Страница Беспроводная сеть больше не падает с ошибкой, когда настроена сеть MLO.
- После обновления старые копии файлов прошивки в общем разделе настроек больше не перекрывают новые.
- Память, которую занимает TrustZone, теперь зарезервирована, как в заводской прошивке. Свободной памяти стало на 6,5 МБ меньше.
- Перенос настроек на USB-диск переживает обновление. SSD с UAS видны при загрузке. Нашёл kazanova-sgh.
- Страница Накопитель больше не предлагает стереть занятый диск или раздел подкачки.
- В теме Nimbus снова открываются выпадающие списки, например MAC в статической аренде. Нашёл Alex Zaguzin. Широкие таблицы помещаются в карточку, а новые стили подхватываются без принудительной перезагрузки страницы.
- Раздача интернета с iPhone по USB снова ставится из фида.
- Драйвер 5 ГГц больше не падает, когда поиск сетей срывается.

Обновление с 1.x

С версий 1.3.x и с 1.2.3 и новее обновляйтесь через страницу Система, Обновление сборки или через sysupgrade. Настройки сохраняются.

Пакеты, которые вы ставили сами, после обновления ставятся заново под новое ядро. Роутер делает это сам, когда появится интернет. Первая загрузка идёт чуть дольше обычного. Если настройки на USB-диске, роутер один раз перезагрузится сам.

Перед обновлением прочитайте раздел "Обновление на 1.4.0 с версий 1.x" в начале файла 2-update.txt в архиве. Там написано, что сделать до обновления, что будет при первой загрузке, что проверить после и как откатиться. С версий 1.2.2 и старше сначала нужна одна команда, она описана там же.

Установка со стока

Установка делается тем же скриптом из архива по файлу 1-install.txt.

Одно отличие стоит знать заранее. Если заводская прошивка была настроена, после установки роутер останется на её адресе, обычно 192.168.31.1, и с теми же сетями Wi-Fi. Если нет, он будет на 192.168.1.1, а Wi-Fi будет называться OpenWrt-BE7000 с паролем be7000openwrt.

Beam WRT 1.4.0. A new OpenWrt base, MLO, stock settings import, slots and hardware offload.

The firmware moved to a fresh OpenWrt. The kernel is now 6.18.52 instead of 6.18.36, and the Wi-Fi drivers come from backports 7.2. Everything from 1.3.1 works here too.

What is new

- Three 5 GHz modes. Besides one radio and two radios there is now MLO. It is one Wi-Fi 7 network on both radios at once, the lower one runs up to 160 MHz. Wi-Fi 7 devices keep a link on two channels, older ones join like an ordinary network. The mode changes without a reboot.
- Stock settings import. On the first install the firmware takes Wi-Fi, the internet connection and the router address from the factory firmware. One button undoes it all. The factory firmware itself loses nothing.
- The System, Slots page. It shows what each slot holds and which one boots. You can switch to the other slot there or go back to the factory firmware, and the page explains in detail how it works.
- Hardware NAT offload on the PPE network engine. The feature is experimental and off by default. It is turned on at Network, Hardware offload, which also describes it in detail.
- When the country code turns Wi-Fi 7 off on 5 GHz, a warning shows up. The button next to it sets US for 5 GHz.
- The docs got recipes for common tasks and a measurements page with the method.

What is fixed

- Changing the 5 GHz mode can no longer reboot the router.
- The Wireless page no longer fails with an error when an MLO network is set up.
- After an update, old copies of firmware files in the shared settings volume no longer shadow the new ones.
- The memory TrustZone uses is now reserved, as in the factory firmware. Free memory is 6.5 MB smaller.
- Settings moved to a USB disk survive an update. UAS SSDs are seen at boot. Found by kazanova-sgh.
- The Storage page no longer offers to wipe a disk in use or a swap partition.
- Dropdowns in the Nimbus theme open again, for example the MAC of a static lease. Found by Alex Zaguzin. Wide tables fit their card, and new styles load without a hard reload.
- USB tethering from an iPhone installs from the feed again.
- The 5 GHz driver no longer crashes when a scan fails.

Updating from 1.x

From 1.3.x and from 1.2.3 or newer, update with the System, Build update page or with sysupgrade. Settings are kept.

Packages you installed yourself are installed again for the new kernel after the update. The router does it by itself once it is online. The first boot takes a little longer than usual. If your settings live on a USB disk, the router reboots once by itself.

Before updating, read "Updating to 1.4.0 from 1.x versions" at the top of 2-update-en.txt in the archive. It tells what to do before the update, what happens on the first boot, what to check afterwards and how to go back. From 1.2.2 and older one command is needed first, it is described there too.

Installing from stock

Install with the same script from the archive, following 1-install-en.txt.

One difference is worth knowing in advance. If the factory firmware was set up, the router stays at its address after the install, usually 192.168.31.1, with the same Wi-Fi networks. If not, it is at 192.168.1.1, and Wi-Fi is OpenWrt-BE7000 with password be7000openwrt.
