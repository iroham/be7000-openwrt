Beam WRT 1.4.6. Исправление переноса настроек со стока.

Что исправлено

- Перенос настроек со стока отказывался работать, если заводская прошивка сообщала режим `whc_cap`, и писал, что она не в режиме роутера. Этот режим сток выставляет главному роутеру mesh-сети, и он по-прежнему маршрутизирует, это мой недосмотр. Теперь он принимается, отказ остался только для повторителя и режимов точки доступа. Если у вас раньше выходило сообщение «заводская прошивка не работает как роутер (whc_cap)», обновитесь и нажмите перенос ещё раз, возвращаться на сток не нужно.

Обновление с 1.4.5 обычное, настройки не меняются.

Beam WRT 1.4.6. A fix for importing the settings from stock.

What was fixed

- Importing the settings from stock refused to run when the factory firmware reported the mode `whc_cap`, and said it was not running as a router. Stock sets that mode on the main router of a mesh network, and it still routes, this was my oversight. It is accepted now, and the import is refused only for the extender and the access point modes. If you saw the message that the factory firmware does not run as a router (whc_cap), update and press the import again, there is no need to go back to stock.

Updating from 1.4.5 is unchanged, settings stay as they are.

Beam WRT 1.4.6。修复从原厂固件带入设置。

修复内容

- 当原厂固件报告的模式是 `whc_cap` 时，“带入设置”会拒绝执行，并提示原厂固件不是以路由器模式运行的。原厂固件会把这个模式设给 Mesh 网络里的主路由，它仍然在做路由，这是我的疏忽。现在这个模式会被接受，只有中继器和接入点模式仍会被拒绝。如果你之前看到过“原厂固件不是以路由器模式运行的（whc_cap）”这条提示，更新后再点一次带入设置即可，不需要回到原厂固件。

从 1.4.5 更新的方法不变，设置保持不变。
