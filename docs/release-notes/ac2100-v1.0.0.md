# MiWRT 1.0.0 for the Xiaomi Redmi Router AC2100 (pre-release)

The first MiWRT image for a second router. Built with the official OpenWrt 25.12.6 ImageBuilder for ramips/mt7621, profile `xiaomi_redmi-router-ac2100`, with the MiWRT app service, the Nimbus theme, System, Build update and the first-boot defaults on top. Every package comes from the official OpenWrt feeds for mipsel_24kc.

**This is a pre-release for the hardware test programme.** It has not been flashed on a router by the project at the time of tagging. The install text in the archive says what to verify first, and `docs/plans/redmi-ac2100-hardware-test.md` says what to test.

## What is in it

- **The app service**: devices, pausing, people and rooms, guest Wi-Fi and schedules, alerts, speed test, WOL and laptop power, Tuya, the discovery relay and mDNS reflector, pairing and push through the relay. The status answer says which parts this router has (`capabilities`), so the app hides slots, split 5 GHz, USB and the temperature.
- **Wi-Fi defaults** on a fresh install: both bands on as `MiWRT`, the serial number as the password, country GB, no daily group-key renewal on 5 GHz.
- **Software flow offloading on**, hardware offloading and packet steering off by default; `sqm-scripts`, `nlbwmon`, `umdns`, `curl`, `tcpdump-mini` in the image. banIP is not in the image (128 MB of RAM); it installs from the official feed.
- **Updates**: System, Build update and `miwrt-update` take only releases tagged `ac2100-v*`, check the signature of the checksum list with the key in the image, and download from the GitHub Pages mirror first.
- **Identity**: "MiWRT 1.0.0 ... (Redmi AC2100, OpenWrt 25.12.6)" where people read it; OpenWrt 25.12.6 where third-party scripts check.

## Not in it

Anything that needs the BE7000 hardware: two slots, split 5 GHz, MLO, board data, USB, extroot, Docker, the modem page, PPE offload, the Beam WRT add-ons.

## Install

From stock: `1-install-en.txt` in the archive. From OpenWrt 21.02 or newer: sysupgrade. From OpenWrt 19.07 or older: `sysupgrade -F -n` (the image uses DSA).
