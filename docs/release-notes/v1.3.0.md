Ethernet на всех платах. Главный релиз с начала проекта.

На части BE7000 после установки не работал приём по кабелю. Линк есть, а роутер не принимает ни одного кадра, ни по LAN, ни по WAN, работает только Wi-Fi. Месяц мы перебирали порядок запуска, калибровки, такты, сбросы и регистры линии между процессором и микросхемой портов QCA8084, и всё совпадало со стоком до бита. Причина оказалась в питании. В описании платы был регулятор l2 на 1,8 В, доставшийся от эталонной платы Qualcomm, где он питает USB. Из-за него ядро при загрузке отправляло на этот регулятор запрос через RPM, а сток таких запросов не делает вообще. На части плат после этого запроса приёмник процессора на линии к QCA8084 глохнет. Теперь ядро за l2 не голосует, USB питается от фиксированного 1,8 В.

Нашли на плате zerc00l. Он дал удалённый доступ к своему роутеру через малину, и за вечер удалось сделать то, что раньше растягивалось на недели. Сравнили сток и нашу сборку на одной плате, прогнали PRBS в обе стороны и бисекцией нашли одну строчку. После исправления кабель работает на каждой загрузке, iperf3 941 Мбит/с в обе стороны без единой ошибки на линии. BurmecianKnight подтвердил то же на своей плате. Огромное спасибо zerc00l, а BurmecianKnight, Denchik777, fufliks862, dima-dior1999, xiaoqi2020, tera2null и kazanova-sgh за логи, тесты и терпение.

Ещё в релизе
- правка DMA приёма EDMA из основной OpenWrt (автор kravasuper): буферы приёма отображались с одним направлением DMA, а снимались с другим;
- приём Ethernet больше не переносится на одно ядро, EDMA сам раскладывает его по четырём;
- откат на сток больше не сбрасывает настройки стока в зашифрованном sec_cfg;
- страница Система, Благодарности в LuCI с ссылками на всех, кто помог, и тот же список в приветствии по SSH;
- раздел Поддержать проект в README.

Обновление с любой 1.2.x через sysupgrade или страницу Система, Обновление сборки, настройки сохраняются. Со стока тем же скриптом из архива. Если кабель на вашей плате всё ещё не работает, напишите в issue #1 или в тему на 4PDA.

Ethernet on every board. The biggest release since the project started.

On some BE7000 units Ethernet reception did not work after installation: link up, but not a single frame received, on LAN or WAN. The cause was power. The DTS had the MP5496 l2 regulator node from the Qualcomm reference board, the kernel voted it over RPM at boot, and stock never votes any RPM rail. On part of the boards that request silenced the SoC receiver on the 10G-QXGMII lane to the QCA8084. The kernel no longer votes l2, USB gets a fixed 1.8 V supply. Found on zerc00l's board with remote access, confirmed by BurmecianKnight. iperf3 941 Mbit/s both ways, no lane errors.

Also in this release: the EDMA receive DMA fix from OpenWrt main, Ethernet reception spread over four cores, rollback to stock keeps the encrypted stock settings, a System, Credits page in LuCI (same list in the SSH greeting), and a Support the project section in the README.

Update from any 1.2.x with sysupgrade or System, Build update; settings are kept.
