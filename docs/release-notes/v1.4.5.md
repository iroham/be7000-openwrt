Beam WRT 1.4.5. Исправление страницы Слоты.

Что исправлено

- Кнопка на странице Слоты, которая переключает загрузку на слот с заводской прошивкой, могла отвечать `slot 0 holds no firmware this can boot ()`, хотя прошивка в слоте была на месте. Слот, который страница просматривала, иногда не успевал отсоединиться, и повторный просмотр при переключении не удавался. Теперь отсоединение повторяется несколько раз, перед переключением остатки просмотра убираются, а в сообщении об ошибке показана настоящая причина, а не пустые скобки.

Обновление с 1.4.4 обычное, настройки не меняются.

Beam WRT 1.4.5. A fix for the Slots page.

What was fixed

- The button on the Slots page that switches the boot to the slot with the factory firmware could answer `slot 0 holds no firmware this can boot ()` although the firmware was in the slot. The slot that the page had looked at sometimes did not detach in time, and the second look made when switching failed. The detach is now retried a few times, what is left of the look is cleared before the switch, and the error message shows the real reason instead of empty brackets.

Updating from 1.4.4 is unchanged, settings stay as they are.

Beam WRT 1.4.5。修复槽位页面。

修复内容

- 槽位页面上切换到装有原厂固件的槽位的按钮，可能提示 `slot 0 holds no firmware this can boot ()`，但其实槽位里的固件完好。页面查看过的槽位有时来不及断开，切换时再次查看就失败了。现在断开会重试几次，切换前会清理查看留下的残余，错误信息也会显示真实原因，而不是空括号。

从 1.4.4 更新的方法不变，设置保持不变。
