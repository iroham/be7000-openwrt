# MiWRT 1.4.8.1

Safer firmware updates, and everything Beam WRT 1.4.8 brought. Based on Beam WRT 1.4.8. The kernel is the same as in 1.4.7.x, so packages you added stay as they are.

## Safer updates

- **The update now checks what it wrote.** An update erases the MiWRT slot and then writes the new version into it. Once, that write stopped after the erase and left the slot empty, so the router fell back to its factory firmware. Now the written slot is checked before the router restarts into it, and the write is tried a second time if the check fails.
- **A clean fallback.** If the second try fails too, the next start goes straight to the factory firmware in the other slot. MiWRT can then be installed again from there, with its settings still in place.
- **A record of every update.** Each step is written to /etc/miwrt/last-upgrade.log, on the settings volume that no update touches.
- **Clearer texts.** The app and the update alert no longer say the old version stays in the second slot. The update replaces the MiWRT that runs now; the second slot holds the factory firmware.

## From Beam WRT 1.4.8

- **5 GHz firmware crashes no longer reboot the router.** When the 5 GHz module's firmware crashed and restarted, the driver could use tables it had already freed and crash the kernel. Now the firmware restarts and the router keeps running.
- **Network restart offered** after installing a package with a new network protocol (GRE, L2TP, 6in4 and others), since the network learns its protocols only when it starts.
- **roamd** on Services, Add-ons, optional: moving clients between bands and routers. It leaves MLO networks alone and is updated from the feed.
- **install-from-openwrt.sh** in the release archive, for moving to MiWRT from another OpenWrt.
- **Slots page and instructions** say that the commands for coming back from the factory firmware run in the factory firmware.

Install over MiWRT 1.4.7.x from System, Build update, from the app, or with sysupgrade; settings are kept.
