# MiWRT 1.0.2 for the Xiaomi Redmi Router AC2100 (pre-release)

Still a pre-release for the hardware test programme, not yet flashed on a router by the project. Supersedes 1.0.1.

## Fixed

- **Laptop power and Tuya plug control would have failed.** The app runs the SSH client and the Tuya tool under `timeout`. OpenWrt main's BusyBox, which the BE7000 is built from, has that applet; OpenWrt 25.12's, which this image is built from, does not. The image now carries `coreutils-timeout`. Found by checking every command the MiWRT scripts call against 25.12's BusyBox defaults; `strings`, `brctl`, `nslookup`, `logger`, `sha256sum`, `pidof`, `flock`, `mktemp` and `ip route get` are all present, and every `base64` use goes through `openssl`.
- The `iwinfo` command is in the image, for the hardware report and for people at the shell (the app itself talks to iwinfo over ubus, which was already there).

## Confirmed in this round

- Every package feed index the BE7000 1.5.4.1 image points at resolves on GitHub Pages (15 of 15), so 1.5.4.1 users can install packages; this image uses the official 25.12 feeds.
- LuCI 25.12's LED page offers the MiWRT "State" trigger: the trigger declares itself as not a kernel trigger, which that page honours.
- All 17 ucode files pass a syntax check.

Everything else is as in 1.0.1: the full set of MiWRT features the hardware allows, the install, update and recovery texts corrected against OpenWrt's own sources, still marked TESTING until a unit is flashed.
