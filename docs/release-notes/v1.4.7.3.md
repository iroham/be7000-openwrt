# MiWRT 1.4.7.3

Laptop wake works for a laptop that still looks online. Everything else is as in 1.4.7.2. Based on Beam WRT 1.4.7.

- **Wake from the app.** A sleeping laptop often keeps its Wi-Fi link, so the router shows it as online and the app used to offer no way to wake it. The router now takes a wake request for any laptop that is set up: it sends the wake-up signal, asks the laptop until it answers, and reports whether it did.
- **Mac screen.** After waking a Mac the router asks it to light its screen. A Mac set up before this release wakes with a dark screen until its setup command is run once more.

Install over MiWRT 1.4.7.1 or 1.4.7.2 from System, Build update, from the app, or with sysupgrade; settings are kept. Coming from 1.4.7.2 the update is checked against the signature of this build.
