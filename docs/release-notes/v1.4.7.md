Beam WRT 1.4.7. Интерфейс AmneziaWG в LuCI поднимается, в фиде появились другие туннельные протоколы.

Что исправлено

- Интерфейс AmneziaWG, созданный в LuCI на странице Сеть, Интерфейсы, не поднимался. В пакете amneziawg-tools не было скрипта, через который netifd поднимает такой интерфейс, и протокол считался неизвестным. Теперь скрипт и amneziawg_watchdog входят в пакет. Hybrid Failover это не затрагивало, он поднимает AWG сам.
- В фиде появились модули ядра и пакеты LuCI для GRE, L2TP, PPTP, IPIP, VXLAN, 6in4, 6rd, 6to4, DS-Lite, MAP, 464XLAT, relayd, bonding, SSTP, OpenConnect, vpnc и OpenFortiVPN, а также LuCI для модемов MBIM и NCM. Раньше такие интерфейсы нельзя было создать, нужных пакетов в фиде не было. В образ они не входят, ставятся из LuCI на странице Система, Программное обеспечение или через apk. Модули ядра собраны под ядро 1.4.7, поэтому для них нужно обновить прошивку.

Обновление с 1.4.6 обычное, настройки не меняются. Если нужен только AmneziaWG и перепрошиваться не хочется, достаточно обновить один пакет и перезапустить сеть.

```
apk update
apk upgrade amneziawg-tools
/etc/init.d/network restart
```

Beam WRT 1.4.7. AmneziaWG interfaces in LuCI come up, and other tunnel protocols are in the feed.

What was fixed

- An AmneziaWG interface created in LuCI on the Network, Interfaces page did not come up. The amneziawg-tools package lacked the script netifd uses to bring such an interface up, so the protocol was unknown. The script and amneziawg_watchdog are part of the package now. Hybrid Failover was not affected, it brings AWG up on its own.
- The feed now has the kernel modules and LuCI packages for GRE, L2TP, PPTP, IPIP, VXLAN, 6in4, 6rd, 6to4, DS-Lite, MAP, 464XLAT, relayd, bonding, SSTP, OpenConnect, vpnc and OpenFortiVPN, plus LuCI for MBIM and NCM modems. Before, such interfaces could not be created because the packages were missing from the feed. They are not in the image, install them in LuCI on the System, Software page or with apk. The kernel modules are built for the 1.4.7 kernel, so they need the firmware update.

Updating from 1.4.6 is unchanged, settings stay as they are. If you only need AmneziaWG and do not want to flash, upgrading one package and restarting the network is enough.

```
apk update
apk upgrade amneziawg-tools
/etc/init.d/network restart
```

Beam WRT 1.4.7。LuCI 中的 AmneziaWG 接口可以正常启动，软件源中新增了其他隧道协议。

修复内容

- 在 LuCI 的网络、接口页面创建的 AmneziaWG 接口无法启动。amneziawg-tools 软件包里缺少 netifd 启动这类接口所用的脚本，因此该协议被视为未知协议。现在该脚本和 amneziawg_watchdog 已包含在软件包中。Hybrid Failover 不受影响，它自己启动 AWG。
- 软件源中新增了 GRE、L2TP、PPTP、IPIP、VXLAN、6in4、6rd、6to4、DS-Lite、MAP、464XLAT、relayd、bonding、SSTP、OpenConnect、vpnc 和 OpenFortiVPN 的内核模块和 LuCI 软件包，以及 MBIM 和 NCM 调制解调器的 LuCI。此前软件源里缺少这些软件包，无法创建这类接口。它们不在固件镜像中，可在 LuCI 的系统、软件包页面或用 apk 安装。内核模块是为 1.4.7 的内核编译的，因此需要更新固件。

从 1.4.6 更新的方法不变，设置保持不变。如果只需要 AmneziaWG 又不想刷机，只需更新这一个软件包并重启网络。

```
apk update
apk upgrade amneziawg-tools
/etc/init.d/network restart
```
