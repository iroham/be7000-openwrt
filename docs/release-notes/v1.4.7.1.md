# MiWRT 1.4.7.1

Everything from Beam WRT 1.4.1 to 1.4.7 is added, plus laptop power control and two fixes of our own. Nothing MiWRT 1.4.0.3 did is removed or changed. Based on Beam WRT 1.4.7.

## New in MiWRT

- **Laptop power from the app.** Sleep, hibernate, restart, shut down and wake a Windows or macOS laptop. A one-time setup command, made in the app, prepares the laptop; the router then reaches it with its own key and can only send those few requests.
- **Smart plug power-on.** A Tuya Wi-Fi plug on the charger, spoken to on the local network (protocol 3.3 to 3.5, no cloud), starts a laptop that powers on when its charger is connected. Power is cut for 45 seconds. The plug's power reading is recorded: 24 hours of readings and 60 days of energy per day.
- **5 GHz: no periodic group key renewal.** On this radio the renewal could fail for every client at once and disconnect them together at the same time each day.
- **Address service kept running.** If dnsmasq stops, it is started again within 30 seconds and an alert is raised. After a settings change it is stopped and started instead of reloaded, because repeated reloads could leave it stopped.
- **Status page.** The MiWRT mark and links in the Project block; the factory-settings notice has a title and can be hidden.

## From Beam WRT 1.4.1 to 1.4.7

- **MLO** starts reliably and is shown correctly on the Wireless and Overview pages.
- **Docker** (installed on request): containers reach the internet and their ports open from the LAN; the data directory is tested before it is accepted.
- **USB disk as overlay** is mounted again after a firmware update.
- **Package sources:** kernel modules come only from the feed built for this kernel.
- **New-version notice** in the top bar and on Overview. The router asks GitHub for this project's releases once a day; the switch is on System, Build update.
- **LED trigger State (MiWRT)** for any LED. The amber network LED is left as it is.
- **System, Slots:** switching to the factory firmware no longer fails with an empty reason.
- **Stock settings import** also works for the main unit of a Xiaomi mesh.
- **AmneziaWG** interfaces made in LuCI come up.
- **Optional packages in the feed:** Zapret Manager with Zapret, Zapret2, ByeDPI, NetShift, sing-box and hev-socks5-tunnel; GRE, L2TP, PPTP, IPIP, VXLAN, 6in4, 6rd, 6to4, DS-Lite, MAP, 464XLAT, relayd, bonding, SSTP, OpenConnect, vpnc, OpenFortiVPN and MBIM/NCM modem pages. None is installed or switched on by default.

Install over MiWRT 1.4.0.3 from System, Build update, or with sysupgrade; settings are kept.
