# MiWRT 1.4.0.2

First release under the MiWRT name. Based on Beam WRT 1.4.0.

- **Xiaomi board data for both radios.** 5 GHz: stock `bdwlan.b0002`/`b1008` instead of Qualcomm's generic reference entry (on a test unit: transmit power on channel 36 up to the UK/EU limit, 19 → 23 dBm; downlink at 160 MHz ~800 → ~1,000 Mbit/s). 2.4 GHz: stock `bdwlan.b20`. A boot service keeps both in place.
- **Country set on first boot** for radios without one (GB by default), so radar channels and 160 MHz are available.
- **Split-mode fix:** going back to one 5 GHz radio restores its channel and width; before, 5 GHz could stay down.
- **In the image:** sqm-scripts and luci-app-sqm, nlbwmon and luci-app-nlbwmon, banip and luci-app-banip, umdns, tcpdump-mini.
- **Name:** MiWRT in LuCI, the banner, `/etc/openwrt_release`, the help texts in all three languages; default hostname MiWRT.
- Package feed and update page follow this repository.

Install over Beam WRT 1.4.0 or MiWRT 1.4.0.1 with sysupgrade; settings are kept.
