# MiWRT 1.4.7.2

A security release. Everything found in a review of the router service, the phone app, the notification relay and the code taken from Beam WRT is fixed here. Nothing else changes. Based on Beam WRT 1.4.7.

## Pairing and passwords

- **Pairing no longer sends the password.** The app proves to the router that it knows the administrator password, and the router proves the same back, tied to the certificate the app is talking to. A device posing as the router gets nothing it can use. This needs the current app; older app versions still pair the old way.
- **Wrong passwords are counted per device** (5 in 10 minutes), so one device cannot lock everyone else out of pairing.
- **A settings backup asks for the administrator password** as well as the phone's access key, because it contains the Wi-Fi passwords and the router's own keys.
- **Fresh installs:** the first Wi-Fi password is the unit's serial number from its label, typed without the slash, in place of one password shared by every router.

## Firmware updates

- **Releases are signed.** The updater takes files only from this project's releases and refuses one whose signature does not match the key built into the installed firmware. This release is the first to check; 1.4.7.1 and older install it the old way.

## App service

- At most 600 devices are remembered, and a burst of new devices raises one alert in place of one each, so a device that keeps inventing addresses cannot fill the storage or flood the phone.
- IoT watch remembers at most 300 sites per device and raises at most three alerts per device at a time.
- Alerts taken from the system log only count lines written by the access point or the kernel. A device can no longer fake one through the name it gives when it asks for an address.
- The app service's files are readable by the administrator only.

## Laptop power

- The router stores each laptop's identity at setup and checks it on every request, at whatever address the laptop has that day.
- macOS setup: when the setup is what switches Remote Login on, it accepts keys only, no passwords. A Mac that already had Remote Login on is left as it is.

## Notifications

- Each alert carries its time inside the encrypted text, so an old alert cannot be replayed as a new one.
- A relay must be reached over https; plain http is accepted only for a relay on the home network.
- The router passes the relay a random value made by the phone, and the relay then accepts notifications for that phone only with it.

## Build

- The Hybrid Failover feed is rebuilt only when started by hand.

Install over MiWRT 1.4.7.1 from System, Build update, from the app, or with sysupgrade; settings are kept.
