# MiWRT 1.0.1 for the Xiaomi Redmi Router AC2100 (pre-release)

Still a pre-release for the hardware test programme, not yet flashed on a router by the project. This supersedes 1.0.0 and brings the AC2100 image to full parity with the BE7000 on every feature the hardware allows.

## Added since 1.0.0

- **The rest of MiWRT's LuCI additions**, previously BE7000-only, now on this router too: the Status, Overview card with the version and links, the System, Credits page, the "State" LED trigger on System, LEDs with its watcher, the SSH login greeting, and the offer to restart the network after installing a package that adds a protocol (GRE, L2TP, 6in4 and the like).
- **The Overview card and the release-notes link are model-aware**: on the AC2100 the card names this router and links to the AC2100 notes, on the BE7000 it is unchanged.

## Cross-checked against OpenWrt 25.12

The device tree, flash layout, LED map and install path were checked against OpenWrt's own sources for this board:

- flash: single 117.5 MB UBI for the root filesystem and overlay, a 4 MB kernel partition at the second slot, the stock first kernel left in place;
- the install writes `kernel1` and `rootfs0` from stock and sets `uart_en`, `bootdelay` and `flag_try_sys1_failed`, as OpenWrt's support commit gives it;
- the serial console is `ttyS0` under OpenWrt;
- recovery is the stock bootloader's TFTP-with-reset-button flow.

The install, update and recovery texts in the archive carry these and are marked TESTING until a unit is flashed.

## What is in it (unchanged from 1.0.0)

The app service, Wi-Fi defaults (both bands as `MiWRT`, serial as the password, country GB, no 5 GHz group-key renewal), software flow offloading on with hardware offloading and packet steering off, `sqm-scripts`, `nlbwmon`, `umdns`, `curl`, `tcpdump-mini`, the signed `miwrt-update` restricted to `ac2100-v*` releases, and the MiWRT identity in the description with OpenWrt 25.12.6 kept for scripts.

## Not in it

Anything that needs the BE7000 hardware or its own-compiled feeds: two slots and the slot tools, split 5 GHz, MLO, the Xiaomi board data, USB, extroot, Docker, the modem page, PPE offload, and the Beam WRT add-ons (Zapret and the rest) until they are built for mipsel_24kc.
