MiWRT 1.0.0 for the Xiaomi Redmi Router AC2100: installing from the stock firmware

STATUS: TESTING. The MiWRT project has not yet flashed this image on a router.
The flash commands in step 3 are the ones OpenWrt's own support commit for
this device gives (ramips: Add support for Xiaomi Redmi Router AC2100, April
2020) and OpenWrt users have followed since. The way to get a shell on stock
depends on the stock version and is kept current on the OpenWrt wiki page for
the Redmi Router AC2100. Read that page first.

Which router
  Xiaomi Redmi Router AC2100, board RM2100, six antennas, "RM2100" in the
  stock web interface. NOT the Xiaomi Mi Router AC2100 (R2100, a different
  device): its flash layout differs and these files will brick it.

What you need
  - The two files from the release:
    openwrt-ramips-mt7621-xiaomi_redmi-router-ac2100-squashfs-kernel1.bin
    openwrt-ramips-mt7621-xiaomi_redmi-router-ac2100-squashfs-rootfs0.bin
    and sha256sums.txt to check them.
  - A computer on the router's LAN with a cable, and a shell on stock (below).
  - A way back. Stock is not kept on the flash, but the stock bootloader loads
    a stock image over TFTP (see 3-recovery-and-problems-en.txt). Have a stock
    image and a TFTP server ready before you flash.

Step 1. Get a shell on the stock firmware
  Stock has no SSH. The OpenWrt wiki page documents the current way in for each
  stock version. Follow it, copy a static busybox onto the router if the wiki's
  method needs one, and start telnetd as it describes. Then confirm the model
  before touching the flash:
      nvram get model           # RM2100
      cat /proc/mtd             # kernel0, kernel1, rootfs0, rootfs1, overlay

Step 2. Copy the two files to /tmp and check them
      # from your computer (adjust to the wiki's transfer method)
      cat openwrt-ramips-mt7621-xiaomi_redmi-router-ac2100-squashfs-kernel1.bin > /tmp/kernel1.bin
      cat openwrt-ramips-mt7621-xiaomi_redmi-router-ac2100-squashfs-rootfs0.bin > /tmp/rootfs0.bin
      sha256sum /tmp/kernel1.bin /tmp/rootfs0.bin    # compare with sha256sums.txt

Step 3. Write OpenWrt and point the bootloader at it
  OpenWrt takes the second kernel slot (kernel1) and the rootfs that starts at
  rootfs0, which is why the stock first kernel is left in place. These are the
  steps from the OpenWrt support commit, verbatim:
      mtd write /tmp/kernel1.bin kernel1
      nvram set uart_en=1
      nvram set bootdelay=5
      nvram set flag_try_sys1_failed=1
      nvram commit
      mtd -r write /tmp/rootfs0.bin rootfs0
  The last command reboots. The first boot takes two to three minutes: UBI is
  formatted and the Wi-Fi defaults are applied about half a minute in.

Step 4. First contact
  - By cable: the router is 192.168.1.1, user root, no password. Set one under
    System, Administration (the app pairs with that password).
  - By Wi-Fi: both bands come up as "MiWRT" with this router's serial number
    (on the label) as the password. If the serial could not be read the
    password is miwrt-ac2100 and the system log says so. Change it.
  - System, Overview and the console greeting show
    "MiWRT 1.0.0 ... (Redmi AC2100, OpenWrt 25.12.6)"; scripts see OpenWrt 25.12.6.

Step 5. Run the hardware report and keep it
      sh /path/to/hw-report.sh > /tmp/report.txt
  (hw-report.sh is in the release archive; copy it across with the wiki's
  transfer method.) docs/plans/redmi-ac2100-hardware-test.md says what to check.

Coming from another OpenWrt instead of from stock
  OpenWrt 21.02 or newer upgrades with the sysupgrade image (2-update-en.txt).
  OpenWrt 19.07 or older used swconfig; this image uses DSA, so settings cannot
  carry over: flash with
      sysupgrade -F -n openwrt-ramips-mt7621-xiaomi_redmi-router-ac2100-squashfs-sysupgrade.bin
  and set the router up again.
