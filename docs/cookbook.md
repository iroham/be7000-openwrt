# Рецепты

[English](cookbook.en.md)

Готовые рецепты для частых задач. Команды выполняются по SSH на роутере (`ssh root@192.168.1.1`), пакеты ставятся из фида сборки, поэтому роутеру нужен интернет. Если что-то пошло не так, пришлите вывод команды в тему на 4PDA или в issues.

## USB-модем LTE или 5G

Большинству современных модемов хватает ModemManager и драйверов QMI, MBIM и NCM.

```
apk update
apk add modemmanager luci-proto-modemmanager kmod-usb-net-qmi-wwan kmod-usb-net-cdc-mbim kmod-usb-net-cdc-ncm kmod-usb-serial-option
```

Подключите модем, подождите полминуты и проверьте, что его видно:

```
mmcli -L
```

Дальше в LuCI, Сеть, Интерфейсы, Добавить: протокол ModemManager, устройство модема, APN оператора. Зону межсетевого экрана поставьте wan. Модемы Huawei, которые работают по NCM, дополнительно просят `kmod-usb-net-huawei-cdc-ncm`.

## Интернет с телефона по USB

Android. Новые телефоны раздают по NCM, старые по RNDIS, поставьте оба драйвера:

```
apk update
apk add kmod-usb-net-cdc-ncm kmod-usb-net-rndis
```

iPhone. Нужен драйвер ipheth и usbmuxd, который договаривается с телефоном:

```
apk update
apk add kmod-usb-net-ipheth usbmuxd
/etc/init.d/usbmuxd enable
/etc/init.d/usbmuxd start
```

На iPhone подтвердите «Доверять этому компьютеру» и включите режим модема.

Подключите телефон и посмотрите, какой интерфейс появился:

```
dmesg | tail -20
```

Обычно это `usb0` или `eth` с новым номером. В LuCI, Сеть, Интерфейсы, Добавить: протокол DHCP-клиент, это устройство, зона wan.

## Docker

Образы Docker не помещаются во встроенную память, нужен USB-диск. Подключите его, отформатируйте и смонтируйте, как описано в [storage.md](storage.md), затем:

```
be7000-docker setup
```

Скрипт сам найдёт смонтированный диск, на котором есть место, и перенесёт туда данные Docker. Готовые наборы контейнеров запускаются на странице Службы, Docker: стеки. Скрипт ставит и Dockerman, страницу для контейнеров, образов и сетей.

## Режимы 5 ГГц

Блок Режим 5 ГГц вверху страницы Сеть, Беспроводная сеть. Роутер при смене режима не перезагружается, Wi-Fi 5 ГГц пропадает примерно на полминуты.

- Одно радио. Одна сеть на весь диапазон, все каналы, до 160 МГц. Самая высокая скорость для одного устройства.
- Два радио, как 5G-1 и 5G-2 в стоке. Нижнее на каналах 36-64, верхнее от 149. Нижнему можно дать 160 МГц в его настройках, верхнему до 80 МГц. Удобно, когда устройств много.
- MLO. Одна сеть Wi-Fi 7 на оба радио. Устройства с Wi-Fi 7 и MLO держат связь сразу на двух каналах, остальные подключаются к одному из них как к обычной сети.

В режиме двух радио и MLO каждое радио получает половину антенн, поэтому одно устройство работает медленнее, чем в режиме одного радио. Цифры в [benchmarks.md](benchmarks.md).

Ловушка с кодом страны. С некоторыми кодами, среди них RU, прошивка радиомодуля выключает Wi-Fi 7, и точка работает как Wi-Fi 6. Блок Режим 5 ГГц об этом предупреждает, кнопкой рядом код меняется на US. Вместе с кодом меняются правила каналов и мощности.

Из консоли:

```
be7000-5g-split mode           # какой режим сейчас
be7000-5g-split mode split     # два радио
be7000-5g-split mode mlo       # MLO
be7000-5g-split mode single    # одно радио
```

## Настройки из стока

Если роутер пришёл со стока, где уже были настроены Wi-Fi и интернет, при первой загрузке Beam WRT сам берёт оттуда имена и пароли сетей Wi-Fi, подключение к интернету (PPPoE, DHCP или статический адрес) и адрес роутера. На странице Статус, Обзор видно, что перенесено, там же кнопка отмены.

Посмотреть, что лежит в стоке, ничего не меняя:

```
be7000-stock-import preview
```

Перенести вручную и отменить:

```
be7000-stock-import apply
be7000-stock-import undo
```

Сток хранит настройки в зашифрованном контейнере. Скрипт открывает его только на чтение, с копии, так что сток при возврате найдёт их нетронутыми.

## Слоты и возврат на сток

На флеше два слота. Страница Система, Слоты показывает, что в каждом, какой работает и какой загружается по умолчанию, и переключает на другой. Прошивка, которая загрузилась, сама делает свой слот основным, поэтому переключение насовсем. Как вернуться со стока обратно, страница пишет перед переключением. Подробнее о загрузчике в [bootloader.md](bootloader.md).

## Обновление

Система, Обновление сборки: проверка новой версии и установка в один клик, настройки сохраняются. Из консоли:

```
be7000-update check     # есть ли новая версия
be7000-update apply     # скачать, проверить и поставить
```

Установленные вами пакеты после обновления сами переставляются под новое ядро, когда у роутера появится интернет.
